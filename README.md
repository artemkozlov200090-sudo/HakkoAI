# HakkoAI — Android starter project

Проект на Kotlin + Jetpack Compose. Он рассчитан на дальнейшее развитие в самостоятельное приложение с похожей общей структурой интерфейса.

## Уже реализовано в стартовой версии
- Нижняя навигация: Главная, Видео, Создать, Чаты, Профиль
- Каталог демонстрационных персонажей
- Поиск по каталогу и категории
- Экран переписки с локальным демонстрационным вводом
- Заготовки разделов видео, чатов и профиля
- Диалог создания персонажа/голоса
- GitHub Actions workflow для сборки debug APK

## Что пока НЕ подключено
Реальные ответы ИИ, авторизация, облачная база, звонки/видеосвязь, генерация картинок, клонирование/синтез голосов, платежи и серверная модерация. Для них нужны отдельный backend, безопасное хранение секретов и интеграции. Не помещайте API-ключи в Android APK или публичный репозиторий.

## Сборка APK через GitHub с телефона
1. Создайте пустой репозиторий GitHub.
2. Загрузите **все содержимое** этого архива в корень репозитория, сохранив папку `.github/workflows`.
3. Откройте вкладку **Actions**.
4. Выберите **Build HakkoAI APK** и нажмите **Run workflow**.
5. Дождитесь зелёного статуса завершения.
6. Откройте завершённый запуск и скачайте artifact **HakkoAI-debug**.
7. Распакуйте скачанный artifact и установите `app-debug.apk` на Android.

Если сборка завершится ошибкой, пришлите текст ошибки или скриншот страницы Build.
